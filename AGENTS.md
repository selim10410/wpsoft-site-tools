# WPSoft Site Tools çalışma kuralı

- Yalnız mevcut `wpsoft-site-tools` kaynak klasörünü doğrudan düzenle.
- Plugin klasörünü sürüm veya özellik adıyla kopyalama.
- ZIP, build, release, dist ya da nested plugin klasörü oluşturma.
- Canonical plugin bootstrap yolu yalnız `wpsoft-site-tools/wpsoft-site-tools.php` olmalıdır.
